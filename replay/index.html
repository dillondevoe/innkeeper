Who is at the table

worker
Claims the quest under a lease and does the work as real git commits.
researcher
Reads the tool before any work starts and briefs the worker.
gate
Runs the tool and answers PASS or NO with a reason. It can refuse.
voice
Tells you what happened, read back from the record, not from the driver.
board
Not a party member: the plain files that hold the posting, its state and the one-time merge.

What the lines mean

lease: CLAIMED
A worker holds the quest. Another worker that sees the lease stands down (HELD-BY-OTHER).
state=
The quest’s state on the board: open, claimed, done.
commit SHA
A real commit. The hash is replaced so every recording reads the same.
NO … REFUSED
The gate refused. Its reason is what the worker reads next.
PASS
The gate ran the tool and got the right output.
MERGED / ALREADY-MERGED
The result lands exactly once; a second merge is refused.
$TMPDIR/hello-party.SANDBOX
The throwaway sandbox, its path normalized so the recording is identical on any machine.
